How this page runs

The authority is the Julia program in engine/. Continuous integration runs that program and compares it to frontend/site/engine.mjs. The committed file frontend/fixtures/engine-seal.json is the Julia output for the synthetic sample. When this page's sample campaign matches that file, the banner says so. Any other file is labeled as a browser session, not as a sealed run.

Reports you choose stay in this tab. They are not uploaded, stored, or turned into a message to a bureau, a furnisher, or Stripe. Draft letters download only if you ask. Mailing remains a separate human act. This is a document engine, not legal advice.

Round control

Each switch is that round's enabled flag for this session. The Julia program reads rounds/rounds.json on disk; these switches do not change the repository. A held round seals no letters. Field-level and per-failure rounds use the short letter frame. The long frames are selected only for tradeline-granularity rounds, by round order.

Report snapshots

One JSON report per round, in order. The synthetic pair under sample/ is loaded on open. Choosing files replaces that pair for this tab only. Limit 1 MB each.

Evidence gate

Same rule as engine/EvidenceGate.jl: a record is cleared for a draft only when a case status is human_review_required. Anything else is withheld. Produce the file locally with node metro2/evaluate.mjs. The dilute package's dry run matches nothing until independent evidence is entered. Record ids must be tradeline ids, or INQ: plus the creditor name. This page does not run a letter send.
